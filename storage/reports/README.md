# Thư mục lưu PDF trên hosting

Đây là hướng dẫn vị trí lưu file, không phải thư mục tải PDF tự động. Trên Hostinger, tạo thư mục tương ứng trong document root của website hoặc tốt hơn là vùng lưu trữ không cho thực thi PHP. Chỉ tải lên báo cáo khi quyền sử dụng cho phép. File chưa được tải lên sẽ mở từ source_url trong reports/library.json.
